✅ Підрозділ 3.3 містить керівництво з розгортання на Ubuntu Server 24.04 (PM2, Nginx як reverse proxy, SSL через Let's Encrypt/Certbot), керівництво користувача та адміністратора зі скріншотами.

⚠️ **Мертвий код у фрагменті AuctionsPanel** (підрозділ 3.2.2). У наведеному лістингу компонента обчислюються змінні `dir` та `delay`, але жодна з них не передається до компонента `<AuctionCard>`:
```javascript
let dir;   // обчислюється...
const delay = dir === "fly-in-depth" ? "0ms" : "80ms";
return (
  <AuctionCard
    key={auction.id}
    auction={auction}    // dir і delay тут відсутні
    user={user}
    onJoin={handleJoin}
  />
);
```
Якщо ці змінні насправді використовуються у повному коді (наприклад, через `style={{ animationDelay: delay }}`), необхідно навести повний варіант лістингу. Якщо це дійсно мертвий код — прибрати.

⚠️ **Налаштування `cookie: { secure: false }`** у конфігурації сесій (підрозділ 3.2.1). При цьому у підрозділі 3.3 описується production-розгортання з HTTPS (SSL через Certbot). Для HTTPS-середовища необхідно встановлювати `secure: true` — інакше браузер передаватиме cookie і через незахищений HTTP, що є вразливістю. Якщо параметр свідомо `false` для локальної розробки — це слід зазначити в коментарі до коду і вказати, що для production необхідна заміна.

💡 CORS-конфігурація містить hardcoded fallback `'http://localhost:5173'`: `origin: process.env.FRONTEND_URL || 'http://localhost:5173'`. Для виробничого середовища рекомендується не мати localhost в якості дозволеного origin. У production `process.env.FRONTEND_URL` має бути обов'язковим (без fallback) або додаткова перевірка.
